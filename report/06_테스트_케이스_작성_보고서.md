# 06 테스트 케이스 작성 보고서

## 1. 작업 개요

이번 작업에서는 Java 21, JUnit 5 환경을 기준으로 `SHealthBMITest.java`에 20대, 30대, 40대별 BMI 통계 테스트를 추가했다.

요구사항은 각 나이대마다 최소 5개 테스트 데이터를 구성하고, 저체중, 정상, 과체중, 비만 통계 계산과 `weight=0` 누락 체중 보정 규칙을 검증하는 것이다.

## 2. 테스트 대상 파일

- `src/test/java/com/bestreviewer/SHealthBMITest.java`
- `src/main/java/com/bestreviewer/SHealth.java`
- `docs/requirements_analysis.md`

## 3. 테스트 설계 기준

테스트는 요구사항 분석 문서의 다음 규칙을 기준으로 설계했다.

- 20대는 20-29세, 30대는 30-39세, 40대는 40-49세로 분류한다.
- BMI 카테고리는 저체중, 정상, 과체중, 비만 네 가지로 계산한다.
- 통계 결과는 카테고리별 비율, 즉 퍼센트 값으로 검증한다.
- `weight=0`은 누락 체중으로 보고 동일 연령대의 0이 아닌 체중 평균으로 보정한다.
- CSV 입력은 `id,age,weight,height` 헤더를 포함하고, `SHealth.calculateBmi()`에서 헤더를 제외한 데이터만 계산한다.

## 4. 추가한 주요 테스트

### 나이대별 BMI 통계 계산 테스트

`@ParameterizedTest`와 `@CsvSource`를 사용하여 20대, 30대, 40대 각각에 대해 다음 값을 검증했다.

| 나이대 | 총 인원 | 저체중 | 정상 | 과체중 | 비만 |
|---|---:|---:|---:|---:|---:|
| 20대 | 5명 | 20.0% | 40.0% | 20.0% | 20.0% |
| 30대 | 5명 | 20.0% | 40.0% | 20.0% | 20.0% |
| 40대 | 5명 | 20.0% | 40.0% | 20.0% | 20.0% |

각 나이대에는 다음 5개 사례를 포함했다.

- 저체중 사용자 1명
- 정상 사용자 1명
- 과체중 사용자 1명
- 비만 사용자 1명
- `weight=0` 누락 체중 사용자 1명

누락 체중 사용자는 동일 연령대 평균 체중으로 보정된 뒤 정상 BMI 범위에 들어가도록 설계했다. 따라서 정상 비율은 2명 기준인 40.0%가 된다.

### 누락 체중 보정 테스트

20대, 30대, 40대 각각에 대해 `weight=0`인 사용자가 같은 연령대의 평균 체중으로 보정되는지 검증했다.

각 연령대의 유효 체중은 `50.0`, `60.0`, `68.0`, `75.0`이며, 평균은 `63.25`이다.

따라서 누락 체중 사용자의 보정 결과는 다음과 같다.

| 나이대 | 누락 사용자 나이 | 기대 보정 체중 |
|---|---:|---:|
| 20대 | 29세 | 63.25kg |
| 30대 | 39세 | 63.25kg |
| 40대 | 49세 | 63.25kg |

### SHealth API 기반 통합 테스트

임시 CSV 파일을 생성하여 `SHealth.calculateBmi()`와 `SHealth.getBmiRatio()` 흐름을 함께 검증했다.

검증 내용은 다음과 같다.

- CSV 헤더가 제외되고 15개 데이터 행이 계산된다.
- 20대, 30대, 40대별 카테고리 코드 `100`, `200`, `300`, `400`이 각각 기대 비율을 반환한다.
- 임시 CSV 파일은 테스트 종료 후 `Files.deleteIfExists()`로 정리한다.

## 5. 테스트 코드 스타일

이번 테스트에는 다음 스타일을 적용했다.

- 각 테스트에 `@DisplayName`을 추가하여 Given-When-Then 의도를 한글로 표현
- 테스트 본문에 `// Given`, `// When`, `// Then` 주석 추가
- 반복 검증은 `@ParameterizedTest`와 `@CsvSource`로 구성
- 여러 검증이 필요한 경우 `assertAll()` 사용
- 공통 테스트 데이터는 `createTwentyThirtyFortyRecords()`와 `createCsvLines()` 헬퍼 메서드로 분리

## 7. 결론

이번 테스트 케이스 작성으로 20대, 30대, 40대에 대한 BMI 카테고리별 통계 계산이 요구사항대로 검증되었다.

또한 `weight=0` 누락 체중 보정이 동일 연령대 평균 체중을 기준으로 동작하는지 확인했고, 계산기 단위 테스트뿐 아니라 `SHealth` CSV 처리 API를 통한 통합 흐름까지 Green 상태로 검증했다.
